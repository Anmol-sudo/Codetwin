# 🚀 CodeTwin

Fullstack mobile app built with:

## 🔧 Backend (Spring Boot)
- JWT Authentication
- Refresh Token System
- Role-based Authorization
- Post API (Create + Fetch)

## 📱 Android App (Kotlin)
- Login + Auto Login
- Token Storage (SharedPreferences)
- Retrofit + Interceptor
- Auto Refresh Token
- Feed (RecyclerView)
- Create Post Feature
- Swipe to Refresh

## 🧠 Features
- Secure API communication
- Real-time feed updates
- Clean architecture

## 📌 Tech Stack
- Spring Boot
- PostgreSQL
- Kotlin (Android)
- Retrofit
- JWT
